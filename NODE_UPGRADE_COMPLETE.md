## Support & Troubleshooting

### Issue: Wrong Node Version
**Solution:**
```bash
nvm install 20
nvm use 20
nvm alias default 20
```

### Issue: Build fails with missing dependencies
**Solution:**
```bash
rm -rf node_modules package-lock.json
npm install --legacy-peer-deps
npm run build
```

### Issue: Port already in use
**Solution:**
```bash
pkill -f "next dev"
npm run dev
```

**Solution:**
